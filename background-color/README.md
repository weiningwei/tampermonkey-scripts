# Background Color（网页背景色自定义）

一键把网页背景换成预设或自定义颜色。内置多种常用护眼 / 柔和配色，点击即用；自定义颜色支持 R / G / B 三通道输入并实时预览，可保存复用、随时删除；所选颜色全局持久化，打开任意页面自动生效，也可一键恢复网页默认背景。

## 功能特性

- **预设颜色**：内置 8 种常用护眼 / 柔和配色（豆沙绿、杏仁黄、秋叶褐、胭脂红、青草绿、海天蓝、葛巾紫、极简灰），点击色块立即生效，当前生效颜色蓝色描边高亮；**再次点击当前生效的色块可取消该颜色**，恢复网页默认背景。
- **自定义颜色（RGB / HEX 输入 + 实时预览）**：在「输入 RGB 或 HEX 添加自定义颜色」区，填写 R / G / B 三个 0~255 的整数，或直接输入十六进制 HEX 颜色（支持 `#c7edcc` 完整写法与 `#ce3` 三位缩写）；两种输入双向联动，输入过程中色块与色值（如 `#c7edcc · rgb(199, 237, 204)`）实时预览；点击「添加并应用」校验通过后保存到自定义颜色列表并立即生效，也可按 Enter 快速添加。
- **自定义颜色可增删**：保存的自定义颜色显示在「自定义颜色」区，点击应用，悬停色块出现「×」角标可删除；删除当前生效颜色时自动恢复网页默认背景，避免出现色板里找不到的生效色。
- **浮动按钮入口**：页面右下角常驻圆形按钮（🎨），点击即可打开/关闭设置面板，省去进油猴菜单的步骤；面板会紧贴按钮上方弹出（右边缘对齐，上方空间不足时翻到按钮下方）。按钮可拖动到视口任意位置并全局记住，油猴扩展菜单「更换背景色」入口保留，从菜单打开时面板仍在视口顶部居中。不想要常驻按钮时，把脚本 `CONFIG.FLOATING_BUTTON` 设为 `false` 即可。
- **恢复默认**：面板右上角「恢复默认」按钮一键移除背景色覆盖，还原网页原始背景。只取消当前颜色，自定义颜色列表与浮动按钮位置都保留。
- **重置全部设置**：面板底部「重置全部设置」把脚本恢复到初始状态——恢复网页默认背景，并清空自定义颜色列表、把浮动按钮位置还原到默认的右下角；二次确认后执行，不可撤销。与「恢复默认」的区别见面板底部说明文字。
- **全局持久化**：当前颜色与自定义颜色列表通过 `GM_getValue` / `GM_setValue` 跨站点保存，刷新或打开任意页面自动应用，兼容 Tampermonkey / Violentmonkey。
- **生效方式**：直接给 `html` / `body` 打内联 `!important` 背景色，优先级高于站点自身的 `!important` 声明；同时把遮住底色的**近白 / 浅色背景元素**临时置为透明，让颜色透出来：既包括铺满视口的布局容器（SPA 外壳、整页背景层），也包括知乎等内容站的白/浅灰信息流卡片、侧栏、浅色渐变卡片。动态插入的内容（无限滚动）与 SPA 路由切换会自动重扫。深色卡片、深色渐变、彩色按钮、输入框、`position: fixed` 的弹窗遮罩保留原样。
- 仅顶层页面运行（`@noframes`），避免 iframe 内重复注入。
- 面板通过浮动按钮或油猴扩展菜单打开，点击面板以外任意位置或按 Esc 自动关闭。

## 安装

- GreasyFork 安装：[Background Color（网页背景色自定义）](https://greasyfork.org/zh-CN/scripts/605797-background-color-%E7%BD%91%E9%A1%B5%E8%83%8C%E6%99%AF%E8%89%B2%E8%87%AA%E5%AE%9A%E4%B9%89)。
- 手动安装：安装本仓库 `background-color/background-color.user.js`，通用步骤见[根目录 README](../README.md)。

## 适用范围

默认 `@match *://*/*`，即所有 http/https 页面均可生效。如需限定域名，修改脚本头部的 `@match` 即可。

## 使用说明

1. 点击页面右下角的浮动按钮（🎨，可拖动换位），或通过油猴扩展菜单「更换背景色」，打开「背景色设置」面板。
2. 点击预设或自定义色块立即应用；或在下方输入 R / G / B 数值或 HEX 颜色，边输入边预览，点击「添加并应用」保存并生效。
3. 需要还原时点击面板右上角「恢复默认」（仅取消当前颜色，保留自定义颜色）；想把脚本的全部设置清空，点击面板底部的「重置全部设置」。

## 可配置项

脚本顶部 `CONFIG` 对象支持修改：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `PRESETS` | 豆沙绿、杏仁黄、秋叶褐、胭脂红、青草绿、海天蓝、葛巾紫、极简灰 | 预设颜色列表；`rgb` 为 0~255 的三通道数组，`name` 为色块下方显示的名称。修改后对所有站点生效 |
| `FLOATING_BUTTON` | `true` | 是否显示页面右下角的浮动按钮；`false` 时仅能通过油猴扩展菜单打开面板 |

## 注意事项

- 脚本按「近白 / 浅色」判定要置透明的元素（RGB 各通道 ≥ 230）：白卡片、浅灰卡片、浅色渐变会被染色；深色卡片、深色渐变、彩色按钮、照片背景等会保留原样，以免破坏可读性与设计。
- 表单控件（输入框、按钮）与 `position: fixed` 的弹窗、遮罩、登录框不做处理，避免影响输入辨识与交互。
- 恢复默认时，脚本改动过的内联样式会按原样还原。
- 「重置全部设置」会一并清空自定义颜色与浮动按钮位置，执行前请确认；需要保留自定义颜色时改用「恢复默认」。
