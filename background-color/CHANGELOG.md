# Changelog

本项目的所有重要变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.5.1] - 2026-11-17

### Fixed

- 通过浮动按钮打开面板时，面板改为紧贴按钮上方弹出（右边缘与按钮对齐，上方空间不足时翻到按钮下方），不再固定出现在视口顶部中央；通过油猴扩展菜单打开时仍保持顶部居中。

## [0.5.0] - 2026-11-17

### Added

- 面板底部新增「重置全部设置」入口：二次确认后恢复网页默认背景，同时清空自定义颜色列表与浮动按钮位置，相当于把脚本恢复到初始状态。
- 与右上角「恢复默认」明确区分：后者只取消当前背景色，自定义颜色与浮动按钮位置全部保留；面板底部说明文字与两个按钮的悬停提示同步标注这一差异。

## [0.4.3] - 2026-11-16

### Fixed

- 修复知乎等内容站仍有大片白色区域的问题：0.4.2 只清铺满视口的容器，而白/浅灰信息流卡片、侧栏宽度不足视口，仍会盖住底色。现在把所有近白背景元素（RGB 各通道 ≥ 230）一并置为透明，并用 MutationObserver 处理无限滚动等动态插入的内容。
- 浅色渐变卡片（`background: linear-gradient(#fff, #f6f6f6)`，computed 颜色为 transparent）此前会漏掉，现按渐变停靠点判断后一并清理。

### Changed

- 深色卡片、深色渐变、彩色按钮、输入框、`position: fixed` 弹窗遮罩保留原样，避免破坏可读性与交互。

## [0.4.2] - 2026-11-16

### Fixed

- 修复大量站点背景色「不生效」的问题：不少站点把背景画在铺满视口的布局容器（SPA 外壳、整页背景层）上，只改 `html`/`body` 会被挡住。现在会把这类容器临时置为透明，让颜色透出；卡片、正文等局部区域尺寸不足，不受影响。
- `html`/`body` 改用内联 `!important` 上色，优先级高于站点自身的 `!important` 背景声明。
- SPA 路由切换、异步渲染的页面会在加载后与路由变化时重扫一次，避免容器晚生成导致又一次失效。

### Changed

- 恢复默认时按原样还原所有被改动的内联样式，不再只是移除一条样式规则。

## [0.4.1] - 2026-11-16

### Fixed

- 面板打开时按 Esc 现在可以关闭，与点击面板外关闭的行为保持一致。

## [0.4.0] - 2026-11-16

### Added

- 页面右下角新增可拖动的浮动按钮（🎨）：点击即可打开/关闭背景色设置面板，拖动位置全局持久化；新增 `CONFIG.FLOATING_BUTTON` 开关（默认开启，可关闭常驻按钮仅保留油猴菜单入口）。

## [0.3.0] - 2026-11-16

### Added

- 点击当前生效的色块（预设或自定义）可取消该颜色并恢复网页默认背景；生效色块的悬停提示同步说明「当前生效，再次点击取消」。

## [0.2.0] - 2026-11-15

### Added

- 自定义颜色新增 HEX 输入框：支持 `#c7edcc` 完整写法与 `#ce3` 三位缩写，与 R / G / B 三通道输入双向联动，输入时实时预览色块与色值；「添加并应用」对两种输入方式统一校验与去重。

## [0.1.0] - 2026-11-15

### Added

- 首个版本：一键将网页背景替换为预设或自定义颜色。
- 内置 8 种常用护眼 / 柔和配色（豆沙绿、杏仁黄等），点击即用，当前颜色高亮显示。
- 自定义颜色支持 R / G / B 三通道输入，输入时实时预览色块与 HEX 值；可保存为常用色并随时删除，删除当前生效颜色时自动恢复默认。
- 面板右上角「恢复默认」一键还原网页默认背景。
- 当前颜色与自定义色板全局持久化，任意页面自动生效。
