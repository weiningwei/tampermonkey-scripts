# Changelog

本项目的所有重要变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.10.0] - 2026-11-22

### Added

- 新增隐藏浮动按钮：面板底部点「隐藏浮动按钮」即可让 🎨 按钮消失（状态全局持久化，刷新和跨站点都保持隐藏），需要时从油猴扩展菜单「显示浮动按钮」恢复；菜单同时提供「隐藏浮动按钮」入口，无需打开面板。「重置全部设置」会把按钮恢复为显示。

## [0.9.0] - 2026-11-22

### Fixed

- 全屏播放时浮动按钮与面板不再压在画面上：进入 Fullscreen API 全屏即隐藏；未走全屏 API 的「网页全屏」（B 站等把播放器用固定定位铺满视口）按正在播放的视频是否铺满视口判断，同样隐藏。退出全屏或暂停播放后恢复，白名单站点保持不显示。

## [0.8.0] - 2026-11-17

### Added

- 「当前站点」区新增「复制整页」：把当前页面的完整 HTML（`<!DOCTYPE html>` + `document.documentElement.outerHTML`，含脚本注入的面板与样式，不做截断）复制到剪贴板，便于反馈整页布局问题；复制失败时回退到控制台并提示。

## [0.7.3] - 2026-11-17

### Changed

- SPA 路由变化（`pushState` / `replaceState` / `popstate` / `hashchange`）的重扫改为 200ms 去抖：不再在路由调用的同步栈里跑全量扫描，连续导航只扫一次，避免切换页面时卡顿。

## [0.7.2] - 2026-11-17

### Changed

- 减少加载期的重复全量扫描：MutationObserver 记录「自上次扫描以来是否有新增节点」，页面没有变化时 `load` 与 1.2s 的定时重扫直接跳过；脚本自己的面板、浮动按钮、选取高亮不计入变化，避免初始化时被自己触发一次重扫。合成页面（4037 节点）实测加载期全量扫描从 2 次降为 1 次，1.2s 定时重扫不再产生样式读取。

## [0.7.1] - 2026-11-17

### Changed

- 浅色清理跳过已经处理过的元素：元素内联背景已是脚本写入的 `transparent !important` 时直接返回，不再调用 `getComputedStyle`。全量重扫不再重复计算这些元素，卡片较多的页面样式读取量约减半。

## [0.7.0] - 2026-11-17

### Changed

- 「恢复默认」改为色板中的「默认」色块，排在预设颜色第一格：代表不转换网页背景，点击即取消当前颜色并还原网页原始背景；当前处于默认状态（未选颜色）时该色块高亮，点击不再有额外动作。

### Removed

- 移除面板右上角的「恢复默认」按钮，功能由「默认」色块承接。面板底部说明改为「「默认」只取消背景色转换」，与「重置全部设置」（清空自定义颜色、站点白名单与浮动按钮位置）依旧分开。迁移方式：原「恢复默认」按钮的位置改到「预设颜色」区第一格。

## [0.6.1] - 2026-11-17

### Fixed

- 「复制页面元素」的元素信息采集加了兜底：遇到取样式或几何信息抛错的异常 DOM（detached 节点等）时，改为复制简版报告（页面地址 + HTML 片段）并把原始错误打到控制台，不再整条复制流程中断。

## [0.6.0] - 2026-11-17

### Added

- 面板新增「当前站点」区：可把本页域名加入白名单，加入后本页立即还原背景并收起浮动按钮，刷新后该域名下不再加载脚本；白名单按 hostname 记录（忽略 path 与查询串），同一域名下所有页面一起生效。
- 白名单列表在面板中直接管理，点条目上的「×」即可移除；在白名单站点上仍可通过油猴菜单打开面板，把自身移出白名单即时恢复生效。
- 新增「复制页面元素」：进入选取模式后鼠标悬停高亮元素，点击即可把该元素的选择器、标签、class、尺寸、定位方式、计算背景色/背景图与 HTML 片段复制到剪贴板，便于反馈与定位问题。
- 「重置全部设置」同步清空白名单，并恢复浮动按钮显示。

## [0.5.1] - 2026-11-17

### Fixed

- 通过浮动按钮打开面板时，面板改为紧贴按钮上方弹出（右边缘与按钮对齐，上方空间不足时翻到按钮下方），不再固定出现在视口顶部中央；通过油猴扩展菜单打开时仍保持顶部居中。

## [0.5.0] - 2026-11-17

### Added

- 面板底部新增「重置全部设置」入口：二次确认后恢复网页默认背景，同时清空自定义颜色列表与浮动按钮位置，相当于把脚本恢复到初始状态。
- 与右上角「恢复默认」明确区分：后者只取消当前背景色，自定义颜色与浮动按钮位置全部保留；面板底部说明文字与两个按钮的悬停提示同步标注这一差异。

## [0.4.3] - 2026-11-16

### Fixed

- 修复知乎等内容站仍有大片白色区域的问题：0.4.2 只清铺满视口的容器，而白/浅灰信息流卡片、侧栏宽度不足视口，仍会盖住底色。现在把所有近白背景元素（RGB 各通道 ≥ 230）一并置为透明，并用 MutationObserver 处理无限滚动等动态插入的内容。
- 浅色渐变卡片（`background: linear-gradient(#fff, #f6f6f6)`，computed 颜色为 transparent）此前会漏掉，现按渐变停靠点判断后一并清理。

### Changed

- 深色卡片、深色渐变、彩色按钮、输入框、`position: fixed` 弹窗遮罩保留原样，避免破坏可读性与交互。

## [0.4.2] - 2026-11-16

### Fixed

- 修复大量站点背景色「不生效」的问题：不少站点把背景画在铺满视口的布局容器（SPA 外壳、整页背景层）上，只改 `html`/`body` 会被挡住。现在会把这类容器临时置为透明，让颜色透出；卡片、正文等局部区域尺寸不足，不受影响。
- `html`/`body` 改用内联 `!important` 上色，优先级高于站点自身的 `!important` 背景声明。
- SPA 路由切换、异步渲染的页面会在加载后与路由变化时重扫一次，避免容器晚生成导致又一次失效。

### Changed

- 恢复默认时按原样还原所有被改动的内联样式，不再只是移除一条样式规则。

## [0.4.1] - 2026-11-16

### Fixed

- 面板打开时按 Esc 现在可以关闭，与点击面板外关闭的行为保持一致。

## [0.4.0] - 2026-11-16

### Added

- 页面右下角新增可拖动的浮动按钮（🎨）：点击即可打开/关闭背景色设置面板，拖动位置全局持久化；新增 `CONFIG.FLOATING_BUTTON` 开关（默认开启，可关闭常驻按钮仅保留油猴菜单入口）。

## [0.3.0] - 2026-11-16

### Added

- 点击当前生效的色块（预设或自定义）可取消该颜色并恢复网页默认背景；生效色块的悬停提示同步说明「当前生效，再次点击取消」。

## [0.2.0] - 2026-11-15

### Added

- 自定义颜色新增 HEX 输入框：支持 `#c7edcc` 完整写法与 `#ce3` 三位缩写，与 R / G / B 三通道输入双向联动，输入时实时预览色块与色值；「添加并应用」对两种输入方式统一校验与去重。

## [0.1.0] - 2026-11-15

### Added

- 首个版本：一键将网页背景替换为预设或自定义颜色。
- 内置 8 种常用护眼 / 柔和配色（豆沙绿、杏仁黄等），点击即用，当前颜色高亮显示。
- 自定义颜色支持 R / G / B 三通道输入，输入时实时预览色块与 HEX 值；可保存为常用色并随时删除，删除当前生效颜色时自动恢复默认。
- 面板右上角「恢复默认」一键还原网页默认背景。
- 当前颜色与自定义色板全局持久化，任意页面自动生效。
